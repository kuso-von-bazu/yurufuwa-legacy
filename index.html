ゆるふわレガシー v1.1 要約

カードプールと禁止リストはレガシーそのまま。デッキ75枚の合計「最安購入価格」で階級を分け、同じ階級同士で対戦します。
高いカードを否定するのではなく、高いカードを「上の階級」に隔離するフォーマットです。主戦場は 1K〜5K級(1,000〜5,000円)。

階級表

価格の決め方

  • 晴れる屋通販の 非Foil・通常状態・言語問わず・在庫あり の最安販売価格。在庫なしなら在庫なし込みの最安、取扱なしなら Scryfall の紙最安USD×為替。
  • 基本土地は0円(氷雪基本・荒地を含む)。
  • どの版を実際に使ってもOK。判定は常に最安版。判定するのは資産価値ではなく「今からこのデッキを組む最低費用」。
  • メイン+サイドを合算。分割/両面/出来事カードは1枚扱い。

ゆるふわ判定(価格変動対策)

  • 階級は判定日の価格で決まり、証明コードは 30日間有効。
  • 合計が上限の 110%以内なら同じ階級(猶予)。主催者は「猶予なし」を宣言できる。
  • 値下がりは即反映(下の階級になるだけ)。急騰しても有効期間内のコードは有効。

対戦・イベント

  • 卓ごとに階級を決める(例「3K卓」)。参加できるのは デッキ階級 ≤ 卓の階級。
  • 対戦前に証明コードを見せる。相手は「検証」タブで確認。
  • 1枚でも変えたら再判定(ハッシュが変わる)。
  • 主催者オプション: 猶予あり/なし、実物ルール(対面既定)/プロキシ可(オンライン推奨)。プロキシ可でも階級は実カード価格で判定。

SpellTable / Discord での使い方

  1. 判定して「SpellTable用テキストをコピー」。
  2. ゲーム名の先頭に貼る: [ゆるふわ 3K] YFL1.3K.XXXXXXXX.20260908.2860.K7
  3. 卓に入る人は階級に合うデッキで参加し、自分のコードをチャットに貼る。
  4. 配信する人は「オーバーレイ画像を保存」でバッジPNGを出してOBSに載せる。
